# Process Flow Diagram: Ultra-Efficient V2.0 ($1/gal Target Pathway)

## 1. Process Overview & Stream Block Diagram

The V2.0 process eliminates thermal drying, purchased $CO_2$, and synthetic fertilizers by integrating Hydrothermal Liquefaction (HTL), Catalytic Hydrothermal Gasification (CHG), power plant flue gas capture, and municipal wastewater feeds.

```
 +---------------------------------------------------------------------------------------------------------+
 | ULTRA-EFFICIENT V2.0 PROCESS FLOW SCHEMATIC                                                             |
 +---------------------------------------------------------------------------------------------------------+
 |                                                                                                         |
 |  [Free Flue Gas CO2] ---> [ HYBRID PBR-ORP ] ---> [ DAF & MEMBRANE ] ---> [ HTL REACTOR ]               |
 |  [Wastewater N/P] ------>  (Deep Sumps)            (20% Wet Paste)         (350°C, 20 MPa)              |
 |                                                                                 |                       |
 |                                                                     +-----------+-----------+           |
 |                                                                     |                       |           |
 |                                                              Raw Biocrude            Aqueous Phase      |
 |                                                                     |                       |           |
 |                                                                     v                       v           |
 |  [Drop-in Diesel] <--- [ HYDROTREATING ] <--------------------------+              [ CHG GASIFIER ]     |
 |  (ASTM D975)            (380°C, NiMo catalyst)                                     (380°C, Ru/C)        |
 |                             ^                                                               |           |
 |                             |                                                               v           |
 |                      [In-situ H2 Supply] <------------------------------------- [ Bio-CH4 / CHP Power ] |
 |                                                                                  (Self-Powered Plant)   |
 +---------------------------------------------------------------------------------------------------------+
```
