# Process Flow Diagram: Baseline V1.0 (Conventional Lipid Extraction)

## 1. Process Overview & Stream Block Diagram

The Baseline V1.0 process uses open raceway ponds fed with purchased liquid $CO_2$ and synthetic chemical fertilizers. Algae biomass is harvested, centrifugally dewatered, thermally dried, hexane-extracted for lipids, and transesterified to Fatty Acid Methyl Esters (FAME biodiesel).

```
 +-------------------------------------------------------------------------------------------------------+
 | BASELINE V1.0 PROCESS FLOW SCHEMATIC                                                                  |
 +-------------------------------------------------------------------------------------------------------+
 |                                                                                                       |
 |  [Purchased CO2 ($60/t)] ---> [ POND CULTIVATION ] ---> [ CENTRIFUGATION ] ---> [ THERMAL DRYER ]    |
 |  [Purchased N & P] ------>   (Open Raceway)              (0.05% -> 15% solids)    (15% -> 92% dry)    |
 |                                                                                      |                |
 |                                                                                      v                |
 |  [Biodiesel Fuel] <--- [ TRANSESTERIFICATION ] <--- [ ALGAL LIPIDS ] <--- [ SOLVENT EXTRACTION ]      |
 |  (FAME)                 (Methanol + KOH)             (Triglycerides)       (Hexane Disruption)    |
 |                                                                                      |                |
 |                                                                                      v                |
 |                                                                             [ Solid Meal Waste ]      |
 |                                                                             ($200/ton credit)         |
 +-------------------------------------------------------------------------------------------------------+
```
